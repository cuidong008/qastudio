# 教师端学情指标统计口径说明

本文档对应教师端页面 `/teacher` 的统计接口 `GET /teacher/stats/overview` 与导出接口 `GET /teacher/export/csv`。

## 1. 统一筛选维度

接口支持以下筛选参数：

- `class_id`：班级维度（通过 `student_class_memberships` 过滤学生集合）。
- `course_id`：课程维度（教师仅可查询其拥有/授课的课程）。
- `chapter_id`：章节维度（必须属于所选课程范围；若仅传章节，会自动收敛到该章节所属课程）。

筛选规则：

- 所有指标均在同一筛选范围内计算，避免口径不一致。
- 当教师没有可见课程时，课程相关统计结果为 0 或空列表。

## 2. 指标定义（/teacher 首页）

### 2.1 预习完成率 `preview_completion_rate`

- 数据表：`preview_records`
- 分子：筛选范围内 `completed = true` 的记录数。
- 分母：筛选范围内预习记录总数。
- 公式：`completed_count / total_count * 100`
- 展示：保留 1 位小数。

### 2.2 高频提问 `top_asked`

- 数据表：`questions_asked`、`course_question_synonyms`
- 过程：
  - 先在筛选范围内按 `(course_id, question_text)` 聚合计数，取前 200。
  - 对问句做归一化和课程同义词映射，再做相似问句聚合。
  - 输出聚合后前 5 条（`question` + `count`）。

### 2.3 习题正确率 `answer_accuracy_rate`

- 数据表：`answer_records`，并关联 `questions` 做课程/章节过滤。
- 分子：筛选范围内 `is_correct = true` 的作答记录数。
- 分母：筛选范围内作答记录总数。
- 公式：`correct_count / total_count * 100`
- 展示：保留 1 位小数。

### 2.4 薄弱知识点 `weak_knowledge_points`（Top 5）

- 数据表：`answer_records`、`questions`、`knowledge_points`
- 过程：
  - 统计筛选范围内每道题的错题次数：`group by question_id`。
  - 从题目 `knowledge_point_ids`（逗号分隔）解析到知识点。
  - 将每道题错题次数累加到对应知识点，得到知识点错题频次。
  - 按频次降序（同频按标题升序）取前 5 个知识点标题返回。

说明：

- 若题目未维护 `knowledge_point_ids`，则该题不会贡献薄弱知识点统计。
- 教师端“生成题目”流程会自动按章节知识点匹配并写入 `knowledge_point_ids`（每题最多 3 个）。
- 历史已存在但未绑定知识点的题目，不会自动补齐；需重新生成或后续补录后才会进入薄弱知识点统计。

## 3. 导出口径（/teacher/export/csv）

导出接口同样支持 `class_id`、`course_id`、`chapter_id`，并使用与页面一致的筛选规则：

- `report=overview`：导出 2 个核心数值指标（预习完成率、习题正确率）。
- `report=preview`：导出筛选范围内预习记录明细。
- `report=answers`：导出筛选范围内作答记录明细。
- `report=qa`：导出筛选范围内提问记录明细（教师端仍要求 `rag_hit = true`）。
